# Paper 1 — Tool-Choice Signaling

Title: *Tool-Choice Signaling and Task-State Preservation in LLM Multi-Agent Systems*.

Authors: Ellen Berhe and Muhammad Hassaan Shaukat.

This directory is the Paper 1 project. It is not part of Paper 2 (`../metric_validation/`). Do not pool their numbers.

## Question

When can a runtime hide tool-execution metadata and still leave the assignment visible? The 108-run cohort could not separate canonicalization from simply keeping the assignment. A later 72-episode holdout on seeds 11–14 compares T1, T2, and T4 and is not pooled with the 108.

## Completed evidence

108 exploratory episodes: seeds 1, 2, and 3, four repetitions, policies T1, T2, and T3, model `gpt-4.1-mini-2025-04-14`, temperature 0.7. Signaling runs and normal-mode runs are both in that total. Raw directories are under `outputs/matched/` and are gitignored (`**/outputs/`).

T1 leaves the tool name visible. T2 canonicalizes the name and keeps the assignment. T3 hides the action event and masks the receiver assignment. T3's lower joint reward is confounded with assignment visibility inside the 108.

The holdout is 72 complete episodes, seeds 11–14, policies T1, T2, and T4, two signaling draws per bit and two utility draws. It is summarized in `T4_MATCHED_RESULTS.md` and is not pooled with the 108. On that holdout, deleting the action event while keeping the assignment removed measured bit dependence, and canonicalization did not show a further benefit.

A later utility cohort is eight T3 episodes on the same seeds. It is summarized in `T3_T4_COMPARISON.md` and is not pooled with the 72 or the 108. Hiding the receiver's assignment, with the event already hidden, matched T4 on seed 12 and produced a duplicate claim on seeds 11, 13, and 14.

The observation contract checks the user prompt returned to the runner. It does not inspect later provider-client rewrites, and a pass does not predict the seed-12 outcome. Equivalence and the assignment projection are declared by the caller. The checker does not decide which fields are safe to hide.
